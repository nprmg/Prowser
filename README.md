# Prowser

Код игры Roblox, который синхронизируется в Roblox Studio через [Rojo](https://rojo.space).

## Структура

| Папка | Куда попадает в Studio | Для чего |
|---|---|---|
| `src/server` | `ServerScriptService.RojoServer` | серверные скрипты |
| `src/client` | `StarterPlayer.StarterPlayerScripts.RojoClient` | клиентские скрипты |
| `src/shared` | `ReplicatedStorage.RojoShared` | общие модули |

Имена файлов задают тип скрипта:

- `*.server.luau` — `Script`
- `*.client.luau` — `LocalScript`
- `*.luau` — `ModuleScript`

Rojo управляет только папками `RojoServer`, `RojoClient` и `RojoShared`. Всё, что уже есть в игре вне этих папок, он не трогает.

Внутри этих трёх папок главное — репозиторий. Если добавить туда что-то вручную в Studio, Rojo удалит это при следующем подключении. Новый код кладите в `src/`.

> **Не давайте папкам проекта имена, которые уже заняты в игре.** Например, `ServerScriptService.Server` — главный серверный скрипт игры.
> - Если совпадёт только имя, Rojo создаст второй объект с тем же именем. Код, который ищет `ServerScriptService.Server`, может получить не тот объект.
> - Если совпадут и имя, и класс (например, существующая папка), Rojo удалит из неё всё, чего нет в репозитории.

## Первая настройка (Windows)

Нужен `rojo.exe` версии 7.7.1. Есть два способа его получить.

**Без установки.** Скачайте `rojo-7.7.1-windows-x86_64.zip` со страницы
https://github.com/rojo-rbx/rojo/releases/tag/v7.7.1 и положите `rojo.exe` в папку репозитория. В git он не попадёт, он есть в `.gitignore`. Команда `rojo` будет работать только из этой папки.

**Через [Rokit](https://github.com/rojo-rbx/rokit).** Скачайте `rokit-...-windows-x86_64.zip` из релизов Rokit, распакуйте и выполните `rokit.exe self-install`. Откройте новый терминал и в папке репозитория выполните `rokit install`.

После этого установите плагин Rojo в Studio и перезапустите Studio:

```
rojo plugin install
```

## Работа

1. Откройте игру в Studio.
2. В папке репозитория запустите сервер Rojo:
   ```
   rojo serve
   ```
   Должно появиться:
   ```
   Rojo server listening:
     Address: localhost
     Port:    34872
   ```
   **Не закрывайте это окно**, пока работаете: если его закрыть, синхронизация прекратится.
3. В Studio: **Plugins → Rojo → Connect**.
4. При первом подключении Rojo покажет список изменений. Нажимайте **Accept**, только если в нём есть лишь:
   - добавление (зелёные строки) папок `RojoServer`, `RojoClient`, `RojoShared` и скриптов в них;
   - правка (синяя строка) имени корня `game` на `Prowser` — так Rojo называет корень проекта.

   Если в списке есть удаление (красные строки) чего-то из игры, нажмите **Abort** и напишите, что именно там было.

   **Не нажимайте Reject.** Эта кнопка переносит состояние Studio обратно в файлы проекта.
   - По умолчанию она просто прервёт подключение.
   - Если в настройках плагина включена двусторонняя синхронизация (Two-Way Sync), она удалит из `src/` то, чего нет в Studio.
5. Чтобы получить новые изменения из репозитория, выполните во втором окне терминала:
   ```
   git pull
   ```
   Rojo сразу перенесёт их в Studio.
6. В Team Create изменения сохраняются в облако сами. В живую игру они попадут только после **File → Publish to Roblox**.

При запуске игры (Play) в Output должны появиться строки
`[Prowser] сервер: ...` и `[Prowser] клиент: ...` — значит, синхронизация работает.

## Если не подключается

**«Couldn't connect to the Rojo server»** означает, что на порту никто не отвечает: сервер Rojo не запущен.

- Проверьте, что `rojo serve` запущен из папки репозитория и окно с ним открыто. Если дважды щёлкнуть по `rojo.exe`, он только покажет справку и закроется.
- Если `rojo serve` пишет `Rojo requires a project file, but no project file was found`, вы не в той папке. Перейдите туда, где лежит `default.project.json`.
- Если пишет `Could not start the Rojo server on 127.0.0.1:34872`, порт занят или зарезервирован Windows. Запустите `rojo serve --port 34873` и в плагине впишите порт `34873`.
- Если сервер запущен, а Studio всё равно не подключается, впишите в плагине в поле адреса `127.0.0.1` вместо `localhost`.

**«Could not sync because user ... is already syncing»** — в Team Create через Rojo может быть подключён только один человек за раз.
